Stolperbeats Pattern Programmer

Hey, I made an app for my Stolperbeats and I'd like to share it. At first I had some banks generated as .txt files, but that never quite gives you enough control over the patterns. With no official web editor around, I built one myself.

Only after building it did I find out I'm not the only one: there are plenty of other similar vibes on the internet that do exactly the same. But hey, it's made now, so you might as well enjoy it.

Runs in your browser. Nothing is uploaded and the page loads nothing from the internet.

Quick start

  1. Press stop on the module, then switch off your case. The module writes to the card when you stop the sequencer.
  2. Put the SD card in your computer and copy all files to a folder. That is your backup.
  3. Click Open files, or drop files on this page. Each file goes to its own tab.
  4. Make your changes and click Save (Ctrl/Cmd+S). Chrome and Edge write straight to the card; other browsers download the file.
  5. Eject the card, put it back in the module and switch on. The module reads the card when it starts.

Look for i next to a setting for what it does and how the module handles it. MIDIMap000–031.txt (MIDI out maps) cannot be edited yet.

Troubleshooting

A bank does not show up on the module

Activate it in the Config tab. The file name must be PatternBank plus three digits and .txt, in the root of the card. A browser download may be called PatternBank004 (1).txt; rename it.

My changes are gone

The module rewrites the card when you stop the sequencer. Edit the card with the module switched off.

Saving fails

The card may be locked (switch on the side of the card), or the browser lost permission. The editor then downloads the file instead.

Hidden files on the card

macOS writes files like ._PatternBank004.txt, .Spotlight-V100 and .fseventsd to the card. The module probably ignores them. To remove the ._ files, run dot_clean -m "/Volumes/NO NAME" in Terminal (use the name of your card).

Factory reset

Delete all files from the card, or use an empty FAT32 card. The module writes factory files at the next start.

EnvelopeSettings.txt

Open EnvelopeSettings.txt from the root of the SD card, or drop it on this page.

It holds the waveform, clock divider and range of the ENV 1 and ENV 2 outputs.

MachineConfig.txt

Open MachineConfig.txt from the root of the SD card, or drop it on this page.

It holds the active pattern banks, the clock and MIDI options and the firmware build.

MachineState.txt

Open MachineState.txt from the root of the SD card, or drop it on this page.

The module starts with this state: tempo, timing, shuffle, feeling, bank, patterns and mutes.
